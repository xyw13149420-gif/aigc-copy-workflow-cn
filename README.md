# AIGC 文案工作流

把一篇宠物主粮电商文案，从 5 分钟压到 3 分钟——但不是「让 AI 随便写」，而是一条**可复现的文案生产管线**：模板库管结构与合规，脚本管变量注入与组合去重，大模型只负责表达。

- 在线看：https://aigc-copy-workflow.app.workbuddy.host/?sharecode=5VLUNOOIS7
- 单文件离线版：直接双击 `aigc_workflow.html`（资源全部内嵌，走本地模板引擎，不联网）

## 它输出什么

一次生成，出 11 段可直接用的物料：

| 段落 | 内容 |
|---|---|
| 商品标题 | 5 条，每条卡 30 字上限，批次内做 Jaccard 去重 |
| 卖点文案 | 每条按「痛点 → 证据 → 结果 → 数字」四段结构 |
| 口播脚本 | 0–35s 分段，带时间轴与画面提示 |
| 分镜与提示词 | 每个分镜出**两套提示词**：图片提示词（画什么、拿去生图）与镜头提示词（景别/机位/焦段/运镜/节奏/时长），各带中英两份 |
| 客服话术 | 售前/物流/售后/催付，每条 80 字内 |
| 合规复核 | 39 条极限词表扫描 + 命中位置 + 替换建议 |
| 效率测算 | 纯人工 vs 人机协作的分环节耗时对比，给到 1/20/50/100 篇 |

## 结构

```
copy_templates.json   模板库：标题骨架 / 卖点四段 / 话术场景 / 分镜 / 极限词表（build 与 Python 引擎共用）
legacy/               第一代 Python 管线，站点不再依赖，留作可复现对照
  aigc_copywriter.py    Python 引擎（仅标准库），命令行入口
  aigc_samples.md       上面命令跑出来的示例输出
src/
  engine.js           与 Python 逐字对齐的 JS 引擎（同种子同输出）
  facets.js           商品名 → 品类 / 物种 / 食材 / 功能 / 品牌的解析
  prompts.js          图片提示词与镜头提示词的组装
  postprocess.js      输出后置校验：30 字、80 字、极限词、条数补齐
  app.js              页面交互（生成、下拉、导出、记录）
  page.template.html  页面模板（原样式）
  skin.css            皮肤层：弥散渐变 + 玻璃卡（只覆盖颜色/圆角/阴影）
  ui.css              组件层：细边框 / 便当盒 / 微交互（只覆盖控件本身）
  build.js            拼装：模板 + 引擎 + 样式 → 两个产物
public/               站点产物（由 build.js 生成）
server/index.js       本地静态服务，只管发文件
data/products.json    演示用商品库（10 个 SKU）
assets/               分镜图与成片样张
```

## 跑起来

```bash
# 构建两个产物：aigc_workflow.html（离线单文件）+ public/index.html（站点版）
npm run build

# 本地起服务，打开 http://127.0.0.1:3000
npm start

# 命令行生成（不需要联网，同种子同结果）
python legacy/aigc_copywriter.py --product "无谷鲜肉成猫粮" --price 129 --spec 1.8kg \
    --audience "1-3岁室内猫主人" --count 5 --seed 7 --out legacy/aigc_samples.md
```

## 几个设计上的选择

- **单一事实源**：下拉选中的商品与手输的商品走同一条 `derive()`，手输的「鸭肉干」不会被硬安一个品牌，也不会把标题写成别的肉。
- **随机可复现**：MT19937 在 JS 和 Python 里各实现一遍，同 `--seed` 两边输出逐字一致，便于回归比对。
- **先规则后模型**：模型跑偏或没连上时，整条链路退化成模板引擎，页面上会明确标出来，不会静默给一段不合格的文案。
- **样式分三层**：模板原样式 → `skin.css` 皮肤层 → `ui.css` 组件层。想换视觉，改后两层即可；想完全回滚，把 `build.js` 里对应的拼接删掉一行。
- **缓存策略**：HTML 永远 `no-cache`，静态资源只有带内容指纹 `?v=` 的才允许长缓存——避免「新页面配旧脚本」导致整页交互失灵。
