效率测算

撰写环节被压到 3 秒，但审校 2 分钟不能省 —— 那是脚本不替人做判断的地方。所有数字按同一口径拆解，可直接复算。

三个设计决定

为什么这套东西比「让模型自由发挥」更可靠。

01 / 分工

模板管结构，脚本管变量

标题骨架、卖点四段结构、话术场景、口播分镜、分镜提示词都写在 copy_templates.json 里，改文案不用改代码；脚本只负责占位符填充、30 字校验、超长回退与批次去重。

02 / 合规

极限词先拦，再谈创意

35 个极限词 + 平台补充词，长词优先匹配避免「最好」被拆成「更」+「好」；白名单护住「最后」「第一时间」这类中性时间表述。命中即按映射表替换并告警。

03 / 复现

同种子，逐字同结果

前端内置 CPython 3.13 的 MT19937 实现（含 choice / shuffle / sample 的抽取语义），因此网页生成结果与命令行 python aigc_copywriter.py --seed 7 完全一致。
